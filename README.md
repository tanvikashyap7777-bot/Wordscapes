# Wordscapes

A simple word-puzzle game inspired by Wordscapes, built with React, TypeScript, and Vite. The project is designed to provide a playable word-finding experience with a dual-language setup and a responsive app layout.

## Overview

This repository contains the front-end game logic, UI, and styling for a Wordscapes-style experience. It uses a modern React setup and can be run as a web app or packaged for mobile using Capacitor.

## Features

- Word-based puzzle gameplay
- Dual-language support
- TypeScript-based app logic
- Responsive UI
- Web and mobile-ready setup via Capacitor

## Tech Stack

- React
- TypeScript
- Vite
- CSS / Tailwind styling
- Capacitor for mobile packaging

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Open the app in your browser at the local Vite URL shown in the terminal.

## Build

To create a production build:

```bash
npm run build
```

## Useful Scripts

- `npm run dev` – start the app locally
- `npm run build` – generate a production build
- `npm run preview` – preview the production build locally
- `npm run lint` – run TypeScript checks
- `npm run cap` – access Capacitor CLI commands

## Project Structure

- `src/` – application source code
- `assets/` – app assets and generated resources
- `dist/` – production build output
- `index.html` – app entry HTML
- `vite.config.ts` – Vite configuration
- `capacitor.config.ts` – Capacitor configuration

## Notes

This project is a lightweight word game app focused on a fun and accessible puzzle experience. It is a good starting point for expanding gameplay, adding more levels, or improving language support.
